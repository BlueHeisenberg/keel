# Contributing

Thank you for the interest — but **outside contributions are not being accepted yet.**

This project is maintained under sole copyright so that licensing decisions across the
wider project family remain open. Accepting a pull request without a contributor
licence agreement in place would close that door permanently, so no CLA means no
merges. A CLA will be put in place before contributions are opened.

In the meantime:

- **Bug reports are welcome and useful.** Open an issue.
- **Questions and design discussion are welcome.** Open an issue.
- **Pull requests will be closed unmerged**, however good they are. Please don't spend
  your time on one.

Forking is of course permitted under the licence.
